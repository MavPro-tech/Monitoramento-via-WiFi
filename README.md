<span id="requisito">
  
 ## 📜Requisitos

Desenvolver um sistema utilizando os microcontroladores ESP32-C3 e ESP32-S3 para monitorar temperatura e umidade via Wi-Fi. Exibir os dados em tempo real e o histórico em uma tela touchscreen, desenvolvida no SquareLine Studio, com configuração de limites de temperatura e acionamento de alertas visuais e sonoros.

<span id="objetivo">
  
## 📌Objetivo da Sprint
O objetivo do projeto é realizar o desenvolvimento integrado de um sistema embarcado para monitoramento, assim, para atingir o resultado esperado, foram estabelecidas as seguintes etapas:<br> 
• Conhecer sobre microcontroladores da família ESP32 (ESP32-C3 e ESP32-S3), suas características e aplicações de conectividade Wi-Fi;  <br>
• Entender os componentes eletrônicos, sensores de temperatura e umidade (DHT22) e circuitos de integração;<br> 
• Entender a arquitetura de comunicação sem fio em tempo real entre os dispositivos;<br> 
• Realizar simulações e desenvolvimento da interface gráfica touchscreen utilizando o SquareLine Studio (exportada para LVGL);<br> 
• Criar o croqui do projeto e a montagem física. <br> 

<span id="desenvolvimento">
  
## 📚Desenvolvimento

Trabalhamos em equipe utilizando ferramentas como Brainstorm, 5W2H e Canvas do Projeto para organizar ideias, definir objetivos e planejar as etapas. Também realizamos pesquisas técnicas sobre os sensores, os microcontroladores ESP32-C3 e ESP32-S3 e as tecnologias utilizadas, incluindo o desenvolvimento da interface touchscreen pelo SquareLine Studio.
