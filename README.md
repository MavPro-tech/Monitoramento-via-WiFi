<span id="objetivo">
  
## 📌Objetivo do Projeto
> [!IMPORTANT]
>  O objetivo principal deste projeto é desenvolver um sistema de monitoramento de temperatura e umidade via Wi-Fi, utilizando sensores e uma interface com tela touchscreen para a visualização dos dados em tempo real. O sistema busca oferecer o acompanhamento das condições ambientais, o armazenamento do histórico de medições e a configuração de limites de temperatura, com acionamento de alertas visuais e sonoros quando necessário. Dessa forma, pretende-se proporcionar maior praticidade, controle e confiabilidade no monitoramento ambiental.


> **Status do Projeto: Em andamento🚧**


<span id="visão">
  
## 💡Visão do Produto
> [!TIP]
O monitoramento de temperatura e umidade permite integrar conhecimentos de eletrônica, programação e comunicação sem fio no desenvolvimento de soluções tecnológicas. Nesse contexto, o projeto MAVPRO visa desenvolver um sistema de monitoramento ambiental via Wi-Fi, utilizando sensores, um microcontrolador ESP32 e uma interface touchscreen para visualizar os dados em tempo real. O sistema também permite acompanhar o histórico das medições, configurar limites de temperatura e utilizar alertas visuais e sonoros, proporcionando maior praticidade e controle no acompanhamento das condições ambientais.

<span id="metodologia">
  
## 📚Metodologia
A Metodologia Ágil, a qual utilizamos no produto foi o Scrum, um método ágil adaptativo, iterativo, flexível e eficaz. Entre as ferramentas utilizadas no Scrum, uma é a divisão do projeto em **Sprints**. Para selecionar quais seriam as entregas das nossas Sprints, primeiro definimos nosso **MVP**, priorizando as tarefas que trariam maior entrega de valor para o cliente. 

Dessa forma, com as Tarefas já traçadas, definimos a quantidade de tempo necessário para cada Tarefa, sendo dividido, de maneira mais otimizada, entre os Desenvolvedores do time.

## 📚EAP - Estrutura Analítica do Projeto
A EAP (Estrutura Analítica do Projeto) é um diagrama que organiza o escopo do projeto de forma visual, hierárquica e em partes menores, a fim de facilitar o gerenciamento das entregas. Em outras palavras, é uma ferramenta que organiza o trabalho que será realizado no projeto, representando graficamente e simplificadamente o escopo.

## ✅ Conclusão
O desenvolvimento do projeto MAVPRO possibilitou aplicar conhecimentos de eletrônica, programação e comunicação sem fio na criação de um sistema de monitoramento de temperatura e umidade via Wi-Fi. A integração dos sensores com o ESP32 permite coletar e transmitir os dados, enquanto a interface touchscreen, desenvolvida com o auxílio do SquareLine Studio e da biblioteca LVGL, possibilita a visualização das informações em tempo real, o acompanhamento do histórico das medições e a configuração dos alertas. Dessa forma, o projeto contribuiu para o aprendizado prático e demonstrou como a integração entre hardware e software pode tornar o monitoramento ambiental mais acessível, eficiente e confiável, além de abrir possibilidades para futuras melhorias e novas funcionalidades.
