 ## 📜Requisitos
 
Desenvolver um sistema utilizando os microcontroladores ESP32-C3 e ESP32-S3 para monitorar temperatura e umidade via Wi-Fi. Exibir os dados em tempo real e o histórico em uma tela touchscreen, desenvolvida no SquareLine Studio, com configuração de limites de temperatura e acionamento de alertas visuais e sonoros.

<span id="objetivo">
  
## 📌Objetivo da Sprint
O objetivo desta Sprint é desenvolver e integrar os componentes do sistema de monitoramento de temperatura e umidade, realizando a programação dos ESP32-C3 e ESP32-S3, a configuração da comunicação via Wi-Fi e a criação da interface touchscreen no SquareLine Studio, conforme o planejamento realizado.<br>

<span id="desenvolvimento">
  
## 📚Desenvolvimento

## Introdução
A principal meta do projeto é desenvolver um sistema de monitoramento de temperatura e umidade via Wi-Fi, utilizando os microcontroladores ESP32-C3 e ESP32-S3. O sistema permite visualizar os dados ambientais em tempo real por meio de uma tela touchscreen, acompanhar o histórico das medições e configurar limites de temperatura para o acionamento de alertas visuais e sonoros, oferecendo praticidade e confiabilidade no monitoramento ambiental.<br>

## Roteiro de Montagem
A montagem do sistema foi realizada por meio da conexão dos componentes eletrônicos aos microcontroladores ESP32-C3 e ESP32-S3. Foram utilizados fios jumpers e protoboard para as conexões, além de ferramentas como ferro de solda, fio de estanho, chave de fenda e pinça, quando necessário.<br>

## Componentes
Os principais componentes utilizados no projeto foram os microcontroladores ESP32-C3 e ESP32-S3, o sensor de temperatura e umidade DHT22, a tela touchscreen de 7 polegadas, além de protoboard, fios jumpers e componentes para os alertas visuais e sonoros, como LED e buzzer.<br>
